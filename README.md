# Pagina-Web
Este site tem como objetivo mostrar as conquistas obtidas pela equipe na Olimpíada Brasileira de Tecnologia, focando principalmente em falar sobre o aluno João Lucas Manhaes da Silva, que começou no 9° ano neste ramo, além disso o site explica como foi sua trajetória/desafios enfrentados, com a apresentação de imagens, dos anos de 2024 e 2026. Contei com a utilização de IA para corrigir algumas coisas. Site produzido para um trabalho designado pela professora de Educação Digital.
